# S3 Progression Mod

This repository contains the Java mod and the KubeJS scripts needed for the Progression System for CivTFG Season 3.

## Repository layout

- `java_mod/` - the Forge mod, deploys to the instance's `mods/` folder.
- `kubejs_scripts/` - deploys to the instance's `kubejs/` folder (mirrors `startup_scripts/`/`server_scripts/`).
- `config_files/` - deploys to the instance's `config/` folder. Currently just
  `s3_progression_mod/progression.json`, the single source of truth for tier order,
  gamestage ids, and unlock thresholds - both the Java mod (`ProgressionTiers`) and the
  KubeJS scripts read this same file at runtime instead of hand-copying the data. Edit
  it to rebalance tiers/thresholds; no code changes needed on either side.
